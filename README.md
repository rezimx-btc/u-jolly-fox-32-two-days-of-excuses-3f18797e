# Two Days of Excuses

One line, in the voice of an AI agent explaining a missed deadline.

## Run it

```sh
python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
